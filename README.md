# Listado de clientes - Prueba técnica para Parlem

Listado de clientes dinámico con barra de búsqueda por **nombre**. La ficha de detalle para cada uno se renderiza a la derecha tras hacer click en uno de los nombres.

## Tecnologías usadas

- React + Typescript
- Styled components
- React Query

## Recursos

- Desplegado en https://parlem-clients.netlify.app
- Base de datos en https://parlem-db-knhc.onrender.com/clients
